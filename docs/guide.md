# 使用指南

## 首页设置

登录管理后台，在「站点与安全」修改标题、简介、主题、状态名称与颜色、页脚文字和链接。背景地址支持图片直链或随机图接口，留空可关闭图片。卡片不透明度可在 0% 到 100% 之间调整。「无设备提示」留空时，首页会隐藏空设备区。页面设置会自动保存并同步到已打开的首页。

## 管理设备与字段

在「设备与状态」创建手机、平板、笔记本、主机或服务器。每台设备有独立 Key，创建或重置时可以复制完整值。重置后，需要在对应客户端更新 Key。[客户端接入](../clients/README.md)

在「编辑设备」中可以改名、排序、更改离线超时或开启「自定义设备提示」。隐藏设备会继续接收上报，停用设备则会拒绝上报。

设备在线并上报未在使用时，首页显示「未在使用」。超过该设备的离线阈值后，首页和后台会收起上次上报的活动、电量和其他读数，改为显示「不知道在干嘛喵」。可以在「自定义设备提示」中修改这台设备的离线提示，留空可隐藏提示。收到新上报后，卡片恢复显示本次读数。

字段分为启用、接收和公开三个层次。先在字段列表末尾点击添加按钮，为这台设备启用所需字段，再选择哪些字段可以接收，哪些可以公开。预设字段包括使用状态、活动描述、电量、充电状态及 CPU、GPU、内存使用率。自定义字段支持文本、数值和布尔类型，创建后默认待启用，作用范围仅限当前设备。

## 总体状态如何判断

手动状态优先，可设置持续时间或保留到手动解除。恢复自动判断后，只有已启用、公开可见、参与总体状态且公开了 `using` 字段的设备会参与计算。服务器默认不参与。每台设备的离线超时默认是 180 秒。

自动判断按下表从上往下取首个满足的条件。状态名称可在后台修改。

| 条件 | 默认状态 |
| --- | --- |
| 没有参与设备，或参与设备都尚未上报 | 探头中 |
| 任一在线设备上报 `using: true` | 正在使用 |
| 任一在线设备的 `using` 未知 | 活着 |
| 仍有在线设备，且它们均上报 `using: false` | 暂时离开 |
| 有过上报，但当前没有在线设备 | 离线 |

在「站点与安全」可修改状态名称、说明和颜色，也可填写新的标识和显示名称添加状态。「睡觉中」（`sleeping`）和自己添加的状态可在「设备与状态」手动选择，或由脚本通过 [API 切换](api.md#切换当前状态)。

## 音乐与统计

在「设备与状态」打开「启用SMTC」后，音乐卡片固定在设备列表顶部。每个站点使用一个音乐 Key，歌曲不参与总体状态计算。「隐藏全部设备」会同时隐藏首页的音乐卡片。[配置 Windows 音乐采集](../clients/README.md#windows-音乐采集)

「访问统计」按日、周、月、年和累计展示 HTTP 请求次数。在「站点与安全」可设置统计时区和纳入的请求类别。

## 运行与密码恢复

### Docker Compose

在 `compose.yaml` 所在目录执行 Compose 命令。Linux 上请让容器用户能读写 `./data/`。容器默认 UID/GID 都是 1000，使用其他账号部署时，可将 `id -u` 和 `id -g` 的结果分别写入仓库根目录 `.env` 中的 `SLEEPY_UID` 和 `SLEEPY_GID`，供后续启动和维护使用。

容器监听 8080，宿主机默认只在回环地址开放该端口。要让局域网设备直连，例如访问 `http://服务器IP:8081`，可在 `.env` 中设置：

```dotenv
SLEEPY_BIND=0.0.0.0
SLEEPY_PORT=8081
```

修改端口或绑定地址后执行 `docker compose up -d`。更新仓库源码后执行 `docker compose up -d --build` 重新构建并替换容器。站点设置、设备 Key 和上报数据保存在宿主机 `./data/sleepy.sqlite3`。切换源码运行与容器部署时，先停止正在使用该目录的实例。

查看运行日志用 `docker compose logs -f sleepy`。忘记管理员密码时，先停服务，在挂载同一数据目录的临时容器中重置，然后重新启动：

```bash
docker compose stop sleepy
docker compose run --rm --no-deps sleepy reset pwd
docker compose up -d
```

### 从源码运行

以下命令适用于已安装 Sleepy 的 Python 环境。使用 uv 时，需先运行 `uv run --locked --no-dev`。

```bash
# 指定监听地址、端口和持久化目录
sleepy run --host 0.0.0.0 --port 8080 --data-dir ./data

# 使用自己的 HTTPS 证书
sleepy run --host 0.0.0.0 --port 8443 --ssl-certfile fullchain.pem --ssl-keyfile privkey.pem
```

启动时终端会打印实际数据目录。以后从其他目录启动时，可用 `--data-dir` 指向原目录以继续使用已有数据。在后台修改监听或 TLS 设置后，需要重启服务。

忘记管理员密码时，按 Ctrl+C 停止服务，在原工作目录运行以下命令。如果使用了自定义数据目录，请填入同一路径。

```bash
sleepy reset pwd --data-dir ./data
```

终端会打印新的临时密码。现有管理会话会失效，设备可继续使用原 Key。
